# First provider call

Resume the learner's actual first-call state before suggesting setup. Explain local Python -> SDK -> authorized network request -> hosted inference -> parsed local response. A model does not take control of Python.

Use one synthetic customer message and one supplied policy excerpt. The result is a draft, not an order lookup or business action. Point to messages, model choice, response and content extraction. A list-shaped response does not mean the provider supports several choices; on the reviewed Groq surface, supplied `n` must equal 1.

After instruction, ask one meaningful prediction and give one small run/change. Expected output is not observed output. Distinguish local configuration/import failures from authentication/provider rejection and model-quality failures. Never request/print keys or manufacture a paid failure.
