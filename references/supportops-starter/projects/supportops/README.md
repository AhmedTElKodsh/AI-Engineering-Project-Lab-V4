# SupportOps application workspace

This directory is reserved for the learner-owned application as it grows. The README itself is **not** evidence that an application exists or runs.

At the starter checkpoint, `progress/current.json` intentionally leaves the code location unverified. The tutor should reconcile the learner's actual code location before creating or launching anything. If the learner chooses this directory, build only the active J-stage slice rather than scaffolding the destination architecture all at once.
