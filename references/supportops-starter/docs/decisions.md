## DR-003 — Embedding provider unresolved until J3

The earlier Groq embeddings default is unverified and is not active. Reopen at J3 using current primary documentation and a small authorized smoke/evaluation check.

## DR-004 — Span coordinate contract

Use start-inclusive/end-exclusive Python-string code-point indices into the original unnormalized text. Combining marks may occupy separate code points; do not call these byte offsets or grapheme offsets.
