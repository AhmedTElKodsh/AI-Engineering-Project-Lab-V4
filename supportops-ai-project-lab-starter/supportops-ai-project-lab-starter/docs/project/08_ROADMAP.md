# Delivery roadmap

The destination architecture in this folder is implemented incrementally through J0-J5. This roadmap intentionally avoids a second M0-M7/T001-T030 progress system.

## Required route

J0 first model feature -> J1 structured intake -> J2 within-product transfer -> J3 retrieval and cited answers -> J4 scoped tools and approved simulated action -> J5 one reproducible engineered learning project.

See `../CURRICULUM.md` for teaching order and `RELEASES.md` for runnable stopping points.

## Optional depth after the initial route

Reopen advanced retrieval, persistent vector storage, durable LangGraph recovery, generated SQL, MCP, graph retrieval, model adaptation, queues, CI/CD, deployment, observability platforms, or extra workflows only when a measured limitation or a target role creates a concrete reason.

The detailed product planning files describe the eventual design space. They do not turn every component into a prerequisite for the first useful run.
