# Closed mini-release map

This is a learner-facing view of the J0-J5 route. Release names are not new progress identifiers.

| Release | Stage | Runnable result | Stop when |
|---|---|---|---|
| Reply Drafter | J0 | message + supplied policy -> reviewable draft | first call/result can be inspected and explained |
| Ticket Intake | J1 | message -> validated case fields + source evidence | missing/negated/uncertain cases behave as specified |
| Delivery Transfer | J2 | same intake mechanism handles conflicting attributed records | learner modifies/explains a genuinely new constraint |
| Policy Finder | J3 | query -> ranked policy passages | retrieval can be evaluated without generation |
| Cited Policy Assistant | J3 | query -> supported answer/citations/abstention | retrieval and answer errors can be distinguished |
| Scoped Order Lookup | J4 | trusted context + order ref -> authorized current facts | allowed/blocked/missing/error cases remain distinct |
| Investigation Copilot | J4 | bounded model-tool loop over read tools | arguments, steps and failures are inspectable |
| Approved Replacement Simulation | J4 | exact proposal -> manager approval -> one local simulated effect | mutation/rejection/replay cases produce zero incorrect effects |
| SupportOps Portfolio Release | J5 | one reproducible integrated demo + evaluation + ownership evidence | another person can run it and learner can change/debug/defend it |
