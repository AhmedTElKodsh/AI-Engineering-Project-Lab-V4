# Evidence directory

No application-test, review, experiment, or mastery evidence exists yet.

Save redacted logs and review notes here. Use names such as `T001-tests.txt`, `T001-review.md`, and `T001-teachback.md`. The fields of an evidence entry, the task status values, and the mastery rules are defined in [the progress protocol](../PROGRESS_PROTOCOL.md).

A `done` task needs at least one passing `test` entry and one passing `review` entry, both pointing to existing files. The coach must still inspect whether those files support the claim; the validator checks structure and links, not the truth of their contents.

Never save credentials, raw personal data, or hidden model reasoning.
